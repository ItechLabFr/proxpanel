# ProxPanel 1.7.1-beta.6 — Theme Polish & Productivity

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version finalise la refonte visuelle introduite en beta.3 et améliore la fiabilité des mises à jour PWA.

### Thème clair

- Audit complet des principales surfaces qui restaient sombres.
- Dashboard, cartes, tableaux, formulaires, modales, Administration, recherche, notifications et menus suivent désormais le thème Light.
- La barre du navigateur et la PWA suivent la couleur du thème actif.
- Les consoles noVNC et terminal restent volontairement sombres.

### Administration et productivité

- Nouvelle recherche dans Administration.
- Nouveau bouton **Réinitialiser l’apparence**.
- Raccourcis clavier desktop :
  - `/` : recherche globale ;
  - `G` puis `O` : Vue d’ensemble ;
  - `G` puis `M` : Machines ;
  - `G` puis `N` : Nœuds ;
  - `G` puis `S` : Stockage.
- `Esc` ferme désormais les modales.

### Connexion Proxmox

- Nouveau diagnostic de connexion avec serveur, URL, latence, dernière donnée valide et dernière erreur.
- Test de connexion directement depuis le diagnostic.
- Si Proxmox devient momentanément indisponible, ProxPanel conserve les dernières données valides au lieu de vider immédiatement le dashboard.
- Un bandeau indique clairement que les données sont temporairement non actualisées.

### PWA et mises à jour

- `index.html`, `app.js`, CSS et manifest passent en réseau prioritaire avec cache de secours.
- `index.html`, `sw.js` et `manifest.webmanifest` utilisent des en-têtes de cache stricts.
- Le Service Worker vérifie les nouvelles versions sans réutiliser un vieux cache HTTP.
- Un bouton **Nouvelle version** apparaît lorsqu’une nouvelle version PWA est prête.

## 🇬🇧 English

This release completes the visual redesign introduced in beta.3 and improves PWA update reliability.

### Light theme

- Full audit of main surfaces that still remained dark.
- Dashboard, cards, tables, forms, modals, Administration, search, notifications and menus now follow the Light theme.
- Browser and PWA chrome follow the active theme color.
- noVNC and terminal consoles intentionally remain dark.

### Administration and productivity

- New Administration settings search.
- New **Reset appearance** action.
- Desktop keyboard shortcuts:
  - `/`: global search;
  - `G` then `O`: Overview;
  - `G` then `M`: Machines;
  - `G` then `N`: Nodes;
  - `G` then `S`: Storage.
- `Esc` now closes modals.

### Proxmox connection

- New connection diagnostics showing server, URL, latency, last valid data and last error.
- Connection retest directly from the diagnostics modal.
- Keeps the latest valid dashboard when Proxmox is temporarily unavailable.
- Clearly marks stale data instead of immediately replacing the dashboard with an error page.

### PWA and updates

- `index.html`, `app.js`, CSS and manifest now use network-first behavior with cache fallback.
- `index.html`, `sw.js` and `manifest.webmanifest` use strict cache headers.
- Service Worker update checks bypass stale HTTP cache.
- A **New version** button appears when a fresh PWA version is ready.

## Tests prioritaires / Priority testing

- Thème Light sur Vue d’ensemble, Machines, Administration, Notifications et modales.
- Passage Dark → Light → Graphite → Light sans rechargement.
- PWA iPhone après mise à jour depuis beta.5.
- Coupure temporaire de l’accès Proxmox pour vérifier la conservation des dernières données.
- Recherche Administration et raccourcis clavier desktop.
- Rechargement d’une nouvelle version PWA.
