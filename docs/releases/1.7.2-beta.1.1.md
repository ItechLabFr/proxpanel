# ProxPanel 1.7.2-beta.1.1 — OTA Packaging Hotfix

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Hotfix critique pour les installations ayant rencontré un **502 Bad Gateway** après la mise à jour OTA vers `1.7.2-beta.1`.

### Cause

La beta.1 a introduit `app/lib/reliability.js`, utilisé au démarrage par `server.js`.

Le builder OTA copiait uniquement :

- `server.js`
- `package.json`
- `public/`
- `vendor/`

Le dossier `lib/` n'était donc pas présent dans le ZIP OTA. Après installation, Node.js échouait sur `require('./lib/reliability')`, ce qui arrêtait ProxPanel et provoquait un 502 côté reverse proxy.

### Correction

- Le builder OTA copie désormais **l'intégralité de l'application**.
- `lib/reliability.js` est bien inclus.
- L'updater vérifie les `require()` locaux avant d'activer une nouvelle release.
- La CI construit réellement le ZIP OTA, vérifie la présence de `lib/reliability.js`, démarre le serveur extrait et contrôle `/healthz`.

### Important

Ce hotfix ne remplace pas le contenu prévu pour **1.7.2-beta.2**.  
La beta.2 reste dédiée à **Docker Containers & Stacks**.

Une instance déjà bloquée en 502 doit d'abord repointer sur sa release précédente, redémarrer, puis installer `1.7.2-beta.1.1`.

## 🇬🇧 English

Critical hotfix for installations hitting a **502 Bad Gateway** after the OTA update to `1.7.2-beta.1`.

### Root cause

beta.1 introduced `app/lib/reliability.js`, required by `server.js` at startup.

The OTA builder only copied `server.js`, `package.json`, `public/` and `vendor/`, so `lib/` was missing from the OTA package. Node.js failed on `require('./lib/reliability')`, stopping ProxPanel and causing the reverse proxy to return 502.

### Fix

- The OTA builder now copies the **complete application tree**.
- `lib/reliability.js` is included.
- The updater validates local `require()` dependencies before activating a release.
- CI now builds the real OTA ZIP, checks `lib/reliability.js`, starts the extracted server and checks `/healthz`.

### Important

This hotfix does not consume the planned **1.7.2-beta.2** feature release.  
beta.2 remains dedicated to **Docker Containers & Stacks**.
