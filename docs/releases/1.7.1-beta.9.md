# ProxPanel 1.7.1-beta.9 — Mobile UX & Cluster Health

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version améliore fortement l’utilisation mobile de ProxPanel et refond le widget Santé du cluster.

### Machines sur mobile

- Cartes VM/LXC réellement adaptées au téléphone.
- La case de sélection est intégrée dans l’en-tête de la carte.
- Suppression du libellé Sélection qui débordait.
- CPU, mémoire, stockage et nœud ne se chevauchent plus.
- Console et Actions deviennent de vrais boutons tactiles pleine largeur.
- Filtres Machines empilés proprement sur petit écran.
- Sélection multiple conservée pendant les rafraîchissements.
- Nouvelle barre d’actions groupées fixe au bas de l’écran.
- Compteur de machines sélectionnées.
- Action Tout désélectionner.

### Santé du cluster

- Suppression du gros cercle 100/100.
- Nouveau score santé compact.
- Barre de progression horizontale plus lisible.
- État global et résumé regroupés.
- Nœuds et Stockages séparés dans deux états compacts.
- Alertes, sauvegardes, température et tâches restent visibles dans une grille claire.
- Design cohérent en Light et Dark.

### Mobile et responsive

- Modales détail VM/LXC en plein écran sur téléphone.
- Header de modal toujours accessible.
- Footer/actions sticky sur mobile.
- Passe responsive sur grilles, toolbars, formulaires et cartes communes.
- Réduction des débordements horizontaux.

## 🇬🇧 English

This release significantly improves ProxPanel mobile usage and redesigns the Cluster Health widget.

### Machines on mobile

- VM/LXC cards are truly phone-friendly.
- Selection checkbox is integrated into the card header.
- Removes the overflowing Selection label.
- CPU, memory, storage and node fields no longer overlap.
- Console and Actions become full-width touch-friendly buttons.
- Machine filters stack cleanly on small screens.
- Multi-selection persists across refreshes.
- New fixed bulk-action bar at the bottom of the screen.
- Selected-machine counter.
- Clear-all selection action.

### Cluster Health

- Removes the oversized 100/100 circular gauge.
- Adds a compact health score.
- Adds a clearer horizontal progress bar.
- Groups global state and summary.
- Nodes and Storage use two compact status cards.
- Alerts, backups, temperature and tasks remain visible in a clean grid.
- Consistent design in Light and Dark themes.

### Mobile and responsive

- Full-screen VM/LXC detail modals on phones.
- Modal header remains accessible.
- Sticky mobile modal footer/actions.
- Responsive pass across shared grids, toolbars, forms and cards.
- Reduced horizontal overflow.

## Tests prioritaires / Priority testing

- Machines sur iPhone/PWA.
- Sélection de plusieurs VM/LXC.
- Actions groupées sur mobile.
- Détail VM/LXC sur téléphone.
- Santé du cluster en Light et Dark.
- Dashboard sur écrans 390–430 px.
- Rotation portrait/paysage.
