# ProxPanel 1.7.2-beta.9.3 — Console assets self-hosted

## FR

Cette version corrige définitivement le chargement des consoles intégrées en supprimant la dépendance navigateur à jsDelivr.

- xterm.js 6.0.0 est embarqué dans ProxPanel et servi localement.
- addon-fit 0.11.0 est embarqué localement.
- noVNC 1.7.0 est embarqué localement.
- Les imports console utilisent désormais uniquement des URLs `/vendor/...` du même domaine.
- La Content-Security-Policy revient à `script-src 'self'` et `style-src 'self' 'unsafe-inline'`.
- Le serveur statique prend correctement en charge les modules `.mjs`.
- Les packages OTA, complets, Docker et LXC incluent désormais automatiquement les assets console vendored.

### Symptôme corrigé

```text
xterm.js indisponible : Failed to fetch dynamically imported module:
https://cdn.jsdelivr.net/npm/@xterm/xterm@6.0.0/+esm
```

Cette erreur pouvait ensuite provoquer côté Proxmox :

```text
failed waiting for client: timed out
```

## EN

This release permanently fixes integrated console loading by removing the browser dependency on jsDelivr.

- xterm.js 6.0.0 is bundled with ProxPanel and served locally.
- addon-fit 0.11.0 is bundled locally.
- noVNC 1.7.0 is bundled locally.
- Console imports now use same-origin `/vendor/...` URLs only.
- Content-Security-Policy is back to `script-src 'self'` and `style-src 'self' 'unsafe-inline'`.
- The static server now serves `.mjs` modules with the correct MIME type.
- OTA, full, Docker and LXC packages now automatically include the vendored console assets.
