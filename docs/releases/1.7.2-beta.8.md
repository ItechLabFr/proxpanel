# ProxPanel 1.7.2-beta.8 — Official LXC Launch + Update Recovery

## Français

### 🚀 Installation LXC officielle

La **1.7.2-beta.8** marque le lancement officiel de ProxPanel en **LXC natif Proxmox VE**.

- LXC Debian 13 non privilégié par défaut.
- Exécution native Node.js + systemd, **sans Docker dans le LXC**.
- Architectures officielles : **amd64** et **arm64**.
- Port web : **8080**.
- Commande d’installation publique permanente :
  `bash -c "$(curl -fsSL https://updates.proxpanel.fr/lxc.sh)"`
- Assistant automatisé : Proxmox, architecture, CT ID, CPU, RAM, disque, réseau et canal Beta sont détectés/configurés automatiquement.
- Choix utilisateur conservé pour le stockage du template Debian et le stockage du disque LXC.
- Recommandation par défaut : **2 vCPU, 2 Go RAM, 8 Go disque**.
- Package officiel : `proxpanel-lxc-v1.7.2-beta.8.tar.gz`.

### 🔄 OTA universel + mise à jour complète / réparation

- Le même **package OTA** est utilisable sur les installations **Docker et LXC**.
- Nouvelle **mise à jour complète** depuis Administration → Mises à jour.
- Nouveau mode **Réparer la version actuelle** avec le package complet.
- Données, comptes, paramètres et intégrations sont conservés.
- Validation SHA-256 avant installation.
- Nouvelle release activée via le runtime versionné.
- Contrôle `/healthz` après redémarrage.
- **Rollback automatique** vers la release précédente si la nouvelle release ne devient pas saine.
- Installation manuelle possible avec un ZIP OTA ou un ZIP complet.

### 🧭 Refonte de l’Administration

- Navigation Administration regroupée par usage : Essentiel, Expérience, Services et Maintenance.
- Accueil Administration simplifié avec état de la version, canal OTA, serveurs et sécurité du compte.
- Accès plus direct aux mises à jour et fonctions de maintenance.
- Réduction du nombre d’actions visibles simultanément.
- Nouvelle passe responsive desktop, tablette, mobile et PWA.
- Corrections de débordements, cartes comprimées, actions hors écran et espaces inutiles.

### 🖥️ Modèle processeur des nœuds

Correction du cas **« Processeur — Modèle indisponible »** alors que Proxmox connaît le CPU.

- Lecture de plusieurs variantes du champ CPU renvoyé par l’API Proxmox.
- Les sockets, cœurs, threads et fréquence restent indépendants du nom du modèle.
- Fallback lecture seule via **SSH / `lscpu` / `/proc/cpuinfo`** lorsqu’une connexion PAM permet cette lecture.
- Source du modèle visible : API Proxmox ou SSH/lscpu.
- Cache négatif raccourci afin qu’un modèle temporairement indisponible soit rapidement retesté.
- Diagnostic explicite si le modèle reste inaccessible.
- Aucune valeur CPU n’est inventée.

### 📦 Publication Beta.8

Une publication Beta complète fournit désormais :

- `proxpanel-update-v1.7.2-beta.8.zip` — OTA universel Docker/LXC.
- `proxpanel-v1.7.2-beta.8.zip` — package complet.
- `proxpanel-lxc-v1.7.2-beta.8.tar.gz` — installation LXC native.
- Image Docker officielle **amd64 + arm64**.

Docker reste pleinement supporté. LXC devient une seconde méthode d’installation officielle.

## English

### 🚀 Official LXC installation

**1.7.2-beta.8** officially launches ProxPanel as a **native Proxmox VE LXC** installation.

- Debian 13 unprivileged LXC by default.
- Native Node.js + systemd runtime, **no Docker inside the LXC**.
- Official **amd64** and **arm64** architectures.
- Web port: **8080**.
- Permanent public install command:
  `bash -c "$(curl -fsSL https://updates.proxpanel.fr/lxc.sh)"`
- Automated assistant for Proxmox detection, CT ID, CPU, memory, disk, network and Beta channel defaults.
- Users only choose template storage and LXC rootfs storage when required.
- Default recommendation: **2 vCPU, 2 GiB RAM, 8 GiB disk**.
- Official asset: `proxpanel-lxc-v1.7.2-beta.8.tar.gz`.

### 🔄 Universal OTA + full update / repair

- The same **OTA package** is used by **Docker and LXC** installations.
- New **full update** mode in Administration → Updates.
- New **repair current installation** action using the full package.
- Persistent data, accounts, settings and integrations are preserved.
- SHA-256 validation before installation.
- Versioned runtime release switching.
- Post-restart `/healthz` verification.
- **Automatic rollback** to the previous release when the new release fails health validation.
- Manual OTA ZIP and full ZIP recovery remain available.

### 🧭 Administration redesign

- Administration navigation grouped by purpose.
- Cleaner Administration home.
- Faster access to update and maintenance functions.
- Reduced visual clutter.
- Broad desktop/tablet/mobile/PWA responsive pass.
- Fixes for overflow, compressed cards, off-screen actions and wasted space.

### 🖥️ Node CPU model reliability

- Reads multiple Proxmox CPU model field variants.
- Keeps sockets, cores, threads and frequency independent from model-name availability.
- Read-only SSH fallback through **lscpu** / **/proc/cpuinfo** when PAM credentials allow it.
- Shows whether the CPU model came from the Proxmox API or SSH.
- Shorter negative caching and clearer diagnostics.
- Never fabricates CPU information.

### 📦 Beta.8 release assets

- `proxpanel-update-v1.7.2-beta.8.zip` — universal Docker/LXC OTA.
- `proxpanel-v1.7.2-beta.8.zip` — full package.
- `proxpanel-lxc-v1.7.2-beta.8.tar.gz` — native LXC installation.
- Official multi-architecture Docker image for **amd64 + arm64**.
