# ProxPanel 1.7.1-beta.2 — Infrastructure UX & Monitoring

**Status:** Published GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version regroupe quatre chantiers qui étaient initialement prévus sur plusieurs betas : **stockage VM**, **multi-nœuds**, **responsive global** et **Monitoring**.

### Stockage VM Windows/Linux

- Affichage des disques virtuels configurés dans Proxmox.
- Distinction entre **capacité virtuelle Proxmox** et **occupation réelle du système invité**.
- Utilisation du QEMU Guest Agent quand il est disponible.
- Affichage des partitions, volumes et points de montage remontés par l’agent.
- Taille totale, espace utilisé, espace libre et pourcentage d’occupation.
- État explicite en cas d’indisponibilité : agent absent, arrêté, timeout, permissions insuffisantes, information non supportée ou compteurs filesystem indisponibles.
- Aucun faux `0 Go` lorsque l’occupation interne n’est pas connue.
- Les informations de stockage invité sont conservées pendant les rafraîchissements live.

### Refonte multi-nœuds

- Nouvelle présentation des nœuds sans cartes compressées.
- Suppression de la logique de barres de ressources redondantes dans cette vue.
- Source serveur/cluster clairement affichée.
- CPU, RAM, température, stockage root et uptime lisibles immédiatement.
- Mise en page adaptative pour deux nœuds ou davantage.
- Cohérence renforcée entre vues regroupées et individuelles.

### Responsive global

- Refonte responsive étendue au-delà du login/MFA.
- Meilleure adaptation des pages, cartes, barres d’actions, formulaires, tableaux et modales.
- La table Machines devient une présentation en cartes sur petits écrans.
- Zones tactiles agrandies et modales adaptées au téléphone.
- Safe areas iPhone prises en compte.
- Meilleure utilisation sur iPhone PWA, iPad/tablette et desktop.

### Monitoring

- État de l’API Proxmox.
- Latence ProxPanel → Proxmox.
- Disponibilité des nœuds.
- CPU, RAM, stockage root et température par nœud.
- Santé et capacité des stockages.
- Disponibilité des données QEMU Guest Agent.
- Détection des données périmées.
- Conservation du drill-down RRD et des graphiques historiques.

## 🇬🇧 English

This release combines four workstreams that had originally been planned across several betas: **VM storage**, **multi-node UX**, **global responsive behavior** and **Monitoring**.

### Windows/Linux VM storage

- Displays virtual disks configured in Proxmox.
- Clearly separates **Proxmox virtual capacity** from **actual guest filesystem usage**.
- Uses QEMU Guest Agent when available.
- Displays partitions, volumes and mount points reported by the guest.
- Shows total, used and free space plus usage percentage.
- Explicit unavailable states: missing/stopped agent, timeout, insufficient permissions, unsupported information or missing filesystem counters.
- Never displays a misleading `0 GB` when internal usage is unknown.
- Guest-storage information remains available during live refreshes.

### Multi-node redesign

- New readable node layout without compressed cards.
- Removes redundant resource-bar presentation from this view.
- Clearly identifies the source server/cluster.
- CPU, RAM, temperature, root storage and uptime remain immediately readable.
- Adaptive layout for two or more nodes.
- Better consistency between grouped and individual views.

### Global responsive improvements

- Responsive work now extends beyond login/MFA.
- Improves pages, cards, action bars, forms, tables and modals.
- The Machines table becomes a card-style layout on small screens.
- Larger touch targets and phone-friendly modals.
- iPhone safe-area handling.
- Better usability on iPhone PWA, iPad/tablet and desktop.

### Monitoring

- Proxmox API status.
- ProxPanel → Proxmox latency.
- Node availability.
- Per-node CPU, RAM, root storage and temperature.
- Storage health and capacity.
- QEMU Guest Agent data availability.
- Stale-data detection.
- Keeps RRD drill-down and historical charts.

## Tests prioritaires / Priority testing

- Au moins deux nœuds Proxmox / at least two Proxmox nodes.
- VM Windows avec et sans Guest Agent / Windows VM with and without Guest Agent.
- VM Linux avec et sans Guest Agent / Linux VM with and without Guest Agent.
- LXC pour vérifier l’absence de régression / LXC regression check.
- iPhone PWA portrait.
- iPad/tablette portrait et paysage / iPad/tablet portrait and landscape.
- Desktop.
