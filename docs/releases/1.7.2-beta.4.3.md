# ProxPanel 1.7.2-beta.4.3 — Backup Warning Classification & Rich Diagnostics

## Français

Cette beta corrige le cas réel observé avec Proxmox : un job `vzdump` peut se terminer en `WARNINGS: 1` alors que les sauvegardes ont bien été produites. ProxPanel ne doit pas transformer ce statut en « Sauvegarde échouée / CRITIQUE ».

### Classification

- `OK` → ✅ succès / information
- `WARNING`, `WARNINGS`, `WARNINGS: n` → ⚠️ terminé avec avertissement
- tout autre statut final d’erreur Proxmox → 🔴 échec critique

La même classification est utilisée par le Health Score, les problèmes du panel et les notifications.

### Diagnostics warning / critical

Pour les événements concernés, ProxPanel transmet désormais le maximum de contexte disponible sans exposer de secrets :

- source technique ;
- serveur / cluster et cible ;
- statut brut ;
- code et identifiant incident ;
- type de tâche ;
- utilisateur ;
- début, fin et durée ;
- UPID ;
- VMID/CT détectés dans le log lorsque disponibles ;
- détails et seuils connus ;
- messages d’erreur API ;
- lignes WARNING / ERROR pertinentes ;
- extrait borné des dernières lignes de log.

Les secrets, mots de passe, tokens, clés API, tickets Proxmox, cookies et credentials sont filtrés avant l’envoi.

### Canaux

L’enrichissement s’applique à :

- e-mail HTML et texte ;
- Discord ;
- Telegram ;
- webhook générique ;
- centre Notifications / PWA pour l’état et la criticité.

## English

This patch fixes Proxmox task warning classification and improves diagnostics for warning/critical notifications.

- `OK` → success
- `WARNING(S)` / `WARNINGS: n` → warning
- actual error statuses → critical failure

Warning and critical events now carry richer technical context across email, Discord, Telegram and generic webhooks, while secrets remain centrally redacted.

## Tests prioritaires / Priority tests

- Vérifier un vrai job `WARNINGS: 1` : sujet « Sauvegarde terminée avec avertissement », priorité AVERTISSEMENT.
- Vérifier qu’un `ERROR` reste « Sauvegarde échouée », CRITIQUE.
- Vérifier l’UPID et l’extrait de log dans l’e-mail.
- Vérifier les blocs diagnostic/log dans Discord.
- Vérifier l’apparition de l’avertissement dans le centre Notifications/PWA.
- Vérifier qu’aucun mot de passe/token/ticket n’apparaît dans les sorties.
