# ProxPanel 1.7.2-beta.4.1 — Docker Metrics Dashboard

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version complète la beta.4 avec un **Dashboard Docker graphique proche de l’expérience du Dashboard Proxmox**.

### Graphiques Docker

- **CPU Docker** : 1 h / 24 h / 7 j / 30 j.
- **RAM Docker** : historique de la consommation des conteneurs par rapport à la RAM des hôtes.
- **Réseau Docker** : débit RX/TX calculé depuis les compteurs exposés par Docker.
- **État des conteneurs** : Running, Stopped, Unhealthy et incidents au fil du temps.
- Sélection de **Tous les environnements** ou d’un environnement Portainer précis.
- Rafraîchissement live sans reconstruction complète de la page.

### Mesure CPU

Les pourcentages CPU des conteneurs Docker peuvent dépasser 100 % sur une machine multi-cœurs. Pour le Dashboard global, ProxPanel normalise la somme des consommations par le nombre de CPU des hôtes afin d’afficher un pourcentage plus comparable au Dashboard Proxmox.

### Historique

- Stockage local dans ProxPanel.
- Maximum d’un échantillon par minute lorsque le Dashboard est consulté.
- Le worker Docker continue d’alimenter l’historique en arrière-plan.
- Rétention maximale : **32 jours**.
- Downsampling automatique pour les périodes longues.
- Les snapshots devenus trop anciens sont exclus des nouvelles mesures.

### Réseau

Les débits RX/TX sont calculés à partir de la différence entre deux compteurs Docker successifs. Après un redémarrage ou une remise à zéro des compteurs, ProxPanel repart de zéro au lieu d’afficher un débit négatif.

### Démo publique

La démo inclut des historiques fictifs CPU, RAM, réseau et états de conteneurs pour montrer immédiatement les nouveaux graphiques.

### Topologie

La topologie introduite en beta.4 reste disponible :

VM/LXC Proxmox → environnement Docker → stack → conteneur.

## 🇬🇧 English

This release extends beta.4 with a **graphical Docker Dashboard closer to the Proxmox Dashboard experience**.

- Docker CPU history.
- Docker memory history.
- Docker RX/TX network history.
- Running, Stopped, Unhealthy and incident history.
- 1 h / 24 h / 7 d / 30 d ranges.
- Global or per-Portainer-environment scope.
- Persistent local history with bounded sampling and 32-day retention.
- Live refresh without rebuilding the whole Docker page.
- Public demo historical fixtures.
