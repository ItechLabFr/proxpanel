# ProxPanel 1.7.0-beta.1

**Canal :** Beta  
**Type :** Historique documenté

## Début de la branche 1.7

Première version de la série 1.7.0 beta. Elle marque le passage à la nouvelle numérotation 1.7.0-beta.x et sert de base aux évolutions suivantes.

## Évolutions

- Passage de la numérotation des futures versions à 1.7.0-beta.x.
- Conservation des fondations ProxPanel existantes : Docker, PWA, administration Proxmox et mécanisme de mise à jour.
- Base de travail pour les améliorations OTA, monitoring, TV et sécurité de la branche 1.7.

## Traçabilité

Cette fiche a été reconstruite rétrospectivement. Aucun tag Git ne doit être créé pour cette version tant que le code ou le ZIP original n'a pas été récupéré et vérifié. Cela évite qu'un tag GitHub pointe vers un faux snapshot du code.
