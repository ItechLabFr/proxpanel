# ProxPanel 1.7.2-beta.7 — Automations 2.0 + Node Hardware

## Français

### Automatisations 2.0

- Conditions et branches conditionnelles.
- Retries configurables par étape.
- Timeout par étape.
- Attente d’un état VM/LXC (wait-until).
- Cibles par VMID, tag ou groupe.
- Actions Docker via Portainer.
- Étapes de sauvegarde Proxmox avec suivi de tâche.
- Dépendances entre étapes.
- Prévisualisation / dry-run sans action réelle.
- Modèles de scénarios réutilisables.
- Historique persistant avec résultat détaillé par étape.

### Matériel des nœuds

- Modèle exact du processeur affiché sur chaque carte nœud lorsque Proxmox le fournit.
- Sockets, cœurs, threads et fréquence exposés séparément.
- Informations CPU lisibles dans la fiche détaillée du nœud.
- Aucune donnée matérielle n’est inventée si l’API Proxmox ne la retourne pas.

### Responsive / mobile

- Correction du panneau de navigation Administration qui recouvrait le contenu sur téléphone.
- Correction de la section **Mise à jour manuelle par ZIP (secours)**.
- Le sélecteur de fichier, le bouton **Installer le ZIP** et le bouton **Rollback** restent désormais contenus dans la largeur de l’écran.
- Les boutons deviennent empilés sur les petits écrans.

## English

### Automations 2.0

- Conditions and conditional branches.
- Configurable retries per step.
- Per-step timeouts.
- Wait-until VM/LXC state.
- VMID, tag and group targets.
- Docker actions through Portainer.
- Proxmox backup steps with task tracking.
- Dependencies between steps.
- Preview / dry-run without real actions.
- Reusable scenario templates.
- Persistent execution history with per-step details.

### Node hardware

- Exact CPU model shown on each node card when provided by Proxmox.
- Separate sockets, cores, threads and frequency information.
- Readable CPU hardware section in node details.
- No hardware data is fabricated when the Proxmox API does not expose it.

### Responsive / mobile

- Fixed the Administration navigation panel overlaying page content on phones.
- Fixed the **Manual ZIP update (fallback)** section.
- File selector, **Install ZIP** and **Rollback** buttons now remain inside the phone viewport.
- Buttons stack vertically on narrow screens.

## Test priorities

- Create a scenario with a retry and timeout, preview it, then execute it.
- Target a VM/LXC by tag and verify the resolved targets in dry-run.
- Execute a backup step and verify the recorded task result.
- Execute a Docker container/stack action through Portainer.
- Confirm execution history survives a ProxPanel restart.
- Verify node cards show the exact CPU model returned by Proxmox.
- Verify Administration navigation on iPhone/PWA no longer overlays content.
- Verify manual ZIP update and rollback controls fit inside a narrow mobile viewport.
