# ProxPanel 1.7.1-beta.1 — Console Reliability & Fast Mobile PWA Startup

## 🇫🇷 Français

**Canal :** Beta  
**Thèmes :** Console distante · PWA mobile/iPhone

### Console distante

- Nouveau diagnostic par étapes : authentification Proxmox, création du proxy, connexion réseau, WebSocket et client noVNC/terminal.
- Jusqu’à deux tentatives de reconnexion automatique avec création d’une nouvelle session console.
- Bouton **Réessayer** lorsqu’une reconnexion automatique ne suffit pas.
- Sessions console temporaires portées à 5 minutes pour mieux tolérer les connexions mobiles lentes.
- Interface console adaptée au téléphone et à la tablette avec zones tactiles plus grandes.
- Messages d’erreur plus précis pour identifier où la connexion s’interrompt.

### Démarrage PWA

- Écran ProxPanel affiché immédiatement au lancement, avant le chargement complet de l’application.
- Le premier rendu n’attend plus les données secondaires : audit, mises à jour, automatisations, restaurations et autres informations d’administration chargent en arrière-plan.
- Le dashboard charge d’abord les données essentielles sans historique.
- Les graphiques historiques sont récupérés après le premier affichage.
- L’enregistrement du Service Worker est différé afin de ne pas concurrencer les requêtes critiques.
- Navigation et ressources versionnées servies en priorité depuis le cache avec actualisation en arrière-plan.
- Les CSS/JS versionnés utilisent désormais un cache HTTP longue durée `immutable`.

### Correctifs

- Réduit fortement l’écran vide au démarrage de la PWA sur iPhone.
- Réduit le délai avant que le dashboard devienne utilisable sur téléphone/tablette.
- Améliore la récupération d’une console QEMU interrompue avant son affichage.
- Remplace plusieurs erreurs console génériques par un diagnostic exploitable.

## 🇬🇧 English

**Channel:** Beta  
**Themes:** Remote console · Mobile/iPhone PWA

### Remote console

- Adds step-by-step diagnostics for Proxmox authentication, proxy creation, network connection, WebSocket handshake and noVNC/terminal client startup.
- Adds up to two automatic reconnect attempts using a newly created console session.
- Adds a **Retry** button when automatic reconnection is not enough.
- Extends temporary console sessions to 5 minutes to better tolerate slow mobile connections.
- Improves console layouts on phones and tablets with larger touch targets.
- Provides more precise errors showing where the console connection failed.

### PWA startup

- Shows a ProxPanel startup screen immediately, before the full application bundle is ready.
- The first render no longer waits for secondary data such as audit logs, update information, automations, restore tests and other administration data.
- The dashboard first loads essential data without historical series.
- Historical charts are fetched after the initial screen is visible.
- Service Worker registration is deferred so it does not compete with critical startup requests.
- Navigation and versioned assets are served cache-first with background revalidation.
- Versioned CSS/JavaScript now use long-lived `immutable` HTTP caching.

### Fixes

- Significantly reduces the blank startup period of the installed PWA on iPhone.
- Reduces the time before the dashboard becomes usable on phones and tablets.
- Improves recovery when a QEMU console disconnects before being displayed.
- Replaces several generic console errors with actionable diagnostics.

## Tests prioritaires / Priority testing

- iPad ou tablette Android / iPad or Android tablet
- VM Windows QEMU
- VM Linux QEMU
- LXC terminal
- Réseau mobile ou connexion avec latence / mobile network or higher-latency connection
