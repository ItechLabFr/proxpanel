# ProxPanel 1.7.0-beta.10

**Canal :** Beta  
**Type :** Historique documenté

## Correction des graphiques continus

Correction définitive du rendu des courbes et amélioration du rafraîchissement des ressources PWA.

## Évolutions

- Suppression des propriétés CSS responsables des courbes en pointillés/coupées.
- Utilisation des timestamps réels pour les points historiques quand ils sont disponibles.
- Versionnement des ressources CSS/JS pour éviter l’affichage d’un ancien rendu après OTA.
- Chargement network-first des ressources applicatives importantes.

## Traçabilité

Cette fiche a été reconstruite rétrospectivement. Aucun tag Git ne doit être créé pour cette version tant que le code ou le ZIP original n'a pas été récupéré et vérifié. Cela évite qu'un tag GitHub pointe vers un faux snapshot du code.
