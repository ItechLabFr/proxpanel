# ProxPanel 1.7.0-beta.11

**Canal :** Beta  
**Type :** Historique documenté

## Diagnostic des températures

Ajout d’un diagnostic détaillé lorsque la température d’un nœud ne peut pas être remontée.

## Évolutions

- Identification de la cause précise d’une température indisponible.
- Diagnostics pour client SSH, sshpass, compte PAM, mot de passe, réseau, authentification, lm-sensors et absence de sonde CPU.
- Action recommandée affichée pour chaque diagnostic.
- Diagnostics visibles dans Dashboard, Nœuds et modes TV.

## Traçabilité

Cette fiche a été reconstruite rétrospectivement. Aucun tag Git ne doit être créé pour cette version tant que le code ou le ZIP original n'a pas été récupéré et vérifié. Cela évite qu'un tag GitHub pointe vers un faux snapshot du code.
