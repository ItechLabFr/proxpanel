# ProxPanel 1.7.2-beta.8.3 — Single-node CPU Hardware Fix

## Français

### Correction CPU — serveur unique

Cette version corrige le cas où ProxPanel affichait encore **« Modèle indisponible »** sur une installation avec un seul serveur Proxmox.

Cause identifiée :

- les vues multi-serveurs appelaient bien l’enrichissement matériel des nœuds ;
- les routes historiques **serveur unique** enrichissaient la température mais pas le matériel CPU ;
- la carte Nœud recevait donc uniquement les données brutes de `/cluster/resources` : CPU, RAM, disque et nombre de threads, mais pas `cpuModel`.

Correction :

- ajout de `enrichNodeHardware()` à la route dashboard serveur unique ;
- ajout de `enrichNodeHardware()` à la route live serveur unique ;
- les champs `cpuModel`, `cpuSockets`, `cpuCores`, `cpuThreads`, `cpuMhz`, `cpuModelSource` et les diagnostics sont maintenant transmis à la page Nœuds ;
- comportement serveur unique aligné sur les vues groupées/multi-nœuds.

Le modèle attendu pour ton cas est désormais récupérable sous la forme :

`Intel(R) Core(TM) i5-7500T CPU @ 2.70GHz`

## English

### CPU fix — single-server mode

Fixes the case where ProxPanel still displayed **“Model unavailable”** on single-Proxmox-server installations.

The legacy single-server dashboard/live routes were enriching node temperatures but not node hardware data.

The fix adds node hardware enrichment to both routes so CPU model, sockets, cores, threads, frequency, source and diagnostics now reach the Nodes UI.
