# ProxPanel 1.7.0-beta.7

**Canal :** Beta  
**Type :** Historique documenté

## Canaux OTA Stable / Beta

Mise en œuvre réelle des canaux OTA et d’une identité d’installation persistante.

## Évolutions

- Canal de mise à jour Stable ou Beta persistant et indépendant de la version installée.
- Heartbeat OTA minimal avec installation_id, version et update_channel.
- Re-vérification immédiate des mises à jour lors d’un changement de canal.
- Blocage des downgrades automatiques.
- Affichage distinct de la version installée, du type de version, du canal et de la dernière version disponible.

## Traçabilité

Cette fiche a été reconstruite rétrospectivement. Aucun tag Git ne doit être créé pour cette version tant que le code ou le ZIP original n'a pas été récupéré et vérifié. Cela évite qu'un tag GitHub pointe vers un faux snapshot du code.
