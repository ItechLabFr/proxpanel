# ProxPanel 1.7.1-beta.4 — Urgent Proxmox Connection Hotfix

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version corrige en priorité une régression introduite en **1.7.1-beta.3** qui pouvait faire apparaître ProxPanel comme entièrement déconnecté de Proxmox.

### Connexion Proxmox

- Vérification d'une vue multi-nœuds sauvegardée avant le premier chargement du dashboard.
- Si cette vue n'existe plus ou devient indisponible, retour automatique sur le serveur Proxmox sélectionné.
- Une erreur de groupe dashboard ne fait plus tomber tout le panneau en état « Non connecté ».
- La récupération de session PVE n'est plus autorisée à invalider un dashboard déjà chargé.

### Thèmes et identité

- Le logo ProxPanel reste orange dans tous les thèmes.
- Le logo ne reprend plus la couleur d'accent du thème sélectionné.
- Cache PWA et assets navigateur versionnés en beta.4 pour forcer la récupération du correctif.

## 🇬🇧 English

This version prioritizes a regression introduced in **1.7.1-beta.3** that could make ProxPanel appear fully disconnected from Proxmox.

### Proxmox connection

- Validates a persisted multi-node view before the first dashboard request.
- Automatically falls back to the selected Proxmox server when that view no longer exists or is unavailable.
- A dashboard-group failure no longer makes the whole panel appear disconnected.
- PVE session retrieval can no longer invalidate an already loaded dashboard.

### Themes and identity

- The ProxPanel logo remains orange across every theme.
- The logo no longer inherits the selected theme accent.
- PWA cache and browser assets are versioned as beta.4 to force clients to retrieve the hotfix.

## Tests prioritaires / Priority testing

- Mise à jour depuis 1.7.1-beta.3.
- Serveur Proxmox avec vue serveur simple.
- Vue multi-nœuds existante.
- Ancienne vue multi-nœuds supprimée ou invalide.
- PWA iPhone après fermeture/réouverture complète.
- Changement entre les six thèmes pour vérifier le logo.
