# ProxPanel 1.7.0-beta.15

**Canal :** Beta  
**Thème :** Authentication & Mobile UX

## Refonte de l’authentification

Cette version se concentre sur le premier contact avec ProxPanel : connexion, demande MFA et première installation.

## Nouveautés

- Login entièrement responsive desktop / tablette / téléphone.
- Parcours en deux étapes visuelles pour ne plus comprimer le MFA sous le mot de passe.
- Authenticator avec saisie OTP mobile et validation automatique à 6 chiffres.
- Écrans distincts pour code de récupération et code de secours e-mail.
- Expiration du code e-mail et délai avant renvoi affichés directement.
- Afficher/masquer le mot de passe et avertissement Verr. Maj.
- Confirmation et indicateur de robustesse du mot de passe lors de la première installation.
- Erreurs intégrées au formulaire et conservation du contexte après un échec.
- Safe areas iPhone, 100dvh, clavier virtuel et zones tactiles adaptées.

## Correctifs

- Affichage du login sur petits écrans.
- Boutons MFA comprimés sur mobile.
- Débordements du formulaire avec le clavier logiciel.
- Lisibilité du passage Login → MFA.
