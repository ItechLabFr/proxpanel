# ProxPanel 1.7.0-beta.15 — Authentication & Mobile UX

## 🇫🇷 Français

**Canal :** Beta  
**Thème :** Authentication & Mobile UX

### Refonte de l’authentification

Cette version se concentre sur le premier contact avec ProxPanel : connexion, demande MFA et première installation.

### Nouveautés

- Login entièrement responsive desktop / tablette / téléphone.
- Parcours en deux étapes visuelles pour ne plus comprimer le MFA sous le mot de passe.
- Authenticator avec saisie OTP mobile et validation automatique à 6 chiffres.
- Écrans distincts pour code de récupération et code de secours e-mail.
- Expiration du code e-mail et délai avant renvoi affichés directement.
- Afficher/masquer le mot de passe et avertissement Verr. Maj.
- Confirmation et indicateur de robustesse du mot de passe lors de la première installation.
- Erreurs intégrées au formulaire et conservation du contexte après un échec.
- Safe areas iPhone, `100dvh`, clavier virtuel et zones tactiles adaptées.
- Respect de `prefers-reduced-motion` et amélioration de l’accessibilité clavier.

### Correctifs

- Corrige l’affichage trop compact du login sur téléphone et tablette.
- Corrige les boutons MFA trop petits ou mal répartis sur les écrans étroits.
- Corrige le débordement potentiel du formulaire lorsque le clavier mobile est affiché.
- Corrige les changements de hauteur et de lisibilité pendant le passage Login → MFA.
- Corrige la perte de contexte visuel lors d’un échec de code Authenticator, e-mail ou récupération.

## 🇬🇧 English

**Channel:** Beta  
**Theme:** Authentication & Mobile UX

### Authentication redesign

This release focuses on the first interaction with ProxPanel: sign-in, MFA verification and first-time setup.

### New features and improvements

- Fully responsive sign-in screen for desktop, tablet and mobile.
- Two-step sign-in flow so MFA is no longer squeezed below the password field.
- Authenticator flow with a mobile-friendly 6-digit OTP field and automatic validation when all digits are entered.
- Dedicated screens for recovery codes and e-mail fallback codes.
- Visible e-mail code expiration timer and resend cooldown.
- Show/hide password control and Caps Lock warning.
- Password confirmation and strength indicator during first-time setup.
- Authentication errors displayed directly inside the sign-in card while preserving the current authentication context.
- iPhone safe-area support, `100dvh`, virtual keyboard handling and touch-friendly controls.
- Improved keyboard accessibility and `prefers-reduced-motion` support.

### Fixes

- Fixes the sign-in layout being too compact on phones and tablets.
- Fixes MFA actions being too small or poorly distributed on narrow screens.
- Fixes potential form overflow while the mobile keyboard is open.
- Fixes visual jumps and readability issues when moving from sign-in to MFA.
- Fixes context loss after an invalid Authenticator, e-mail or recovery code.
