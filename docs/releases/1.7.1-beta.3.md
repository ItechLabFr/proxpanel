# ProxPanel 1.7.1-beta.3 — Performance & Administration UX

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version est centrée sur la **rapidité, le chargement intelligent et la lisibilité de l’interface**.

### Performance et chargement

- Premier affichage plus rapide : seules les données indispensables bloquent l’ouverture de l’application.
- Chargement à la demande pour Audit, utilisateurs, automatisations, tests de restauration et données d’administration.
- Déduplication des requêtes GET simultanées.
- Navigation immédiate : la page cible s’affiche avant la fin des appels réseau.
- Mesure des temps API et affichage des requêtes les plus lentes dans **Administration > Application**.
- Historique du dashboard toujours chargé en différé afin de préserver un premier écran rapide.

### Nouvelle Administration

- Administration devient un centre de configuration avec des sous-sections dédiées :
  - Général
  - Serveurs Proxmox
  - Interface & apparence
  - Supervision
  - Notifications
  - Utilisateurs & sécurité
  - Mises à jour ProxPanel
  - Application
  - Avancé
- La page principale affiche uniquement les informations importantes : version, canal OTA, serveurs et 2FA.
- Les réglages lourds ne sont plus tous affichés sur une seule page.

### Navigation latérale

- Hiérarchie plus claire entre Vue globale, Infrastructure, Opérations et Administration.
- Sections repliables avec état mémorisé.
- Élément actif plus visible.
- Badges, espacements, hover et contraste améliorés.
- Meilleur comportement sur mobile/PWA.

### Thèmes

Six thèmes complets sont disponibles :

- **ProxPanel Dark**
- **Graphite Blue**
- **Light**
- **Neon / Cyber**
- **Purple Control**
- **High Contrast**

Les thèmes s’appliquent au menu, cartes, boutons, badges, formulaires, modales et surfaces générales.

### Réglages visuels

- Mode sombre, clair ou automatique.
- Couleur d’accent personnalisée optionnelle.
- Densité compacte ou confortable.
- Menu compact, standard ou large.
- Réduction des animations.
- Prévisualisation immédiate des changements sans rechargement complet.

## 🇬🇧 English

This release focuses on **performance, smarter loading and a clearer interface**.

### Performance and loading

- Faster first render: only essential data blocks application startup.
- On-demand loading for Audit, users, automations, restore tests and administration datasets.
- Concurrent GET request deduplication.
- Immediate navigation: the destination page renders before network loading finishes.
- API timing measurements and a slow-request list in **Administration > Application**.
- Dashboard history remains deferred to keep the first usable screen fast.

### New Administration

- Administration becomes a structured configuration center with dedicated sections:
  - General
  - Proxmox Servers
  - Interface & Appearance
  - Monitoring
  - Notifications
  - Users & Security
  - ProxPanel Updates
  - Application
  - Advanced
- The Administration home page only shows key information: version, OTA channel, servers and 2FA.
- Heavy settings are no longer stacked on one oversized page.

### Sidebar navigation

- Clearer hierarchy between Overview, Infrastructure, Operations and Administration.
- Collapsible sections with persisted state.
- Stronger active item styling.
- Cleaner badges, spacing, hover states and contrast.
- Better mobile/PWA behavior.

### Themes

Six complete themes are included:

- **ProxPanel Dark**
- **Graphite Blue**
- **Light**
- **Neon / Cyber**
- **Purple Control**
- **High Contrast**

Themes apply across the sidebar, cards, buttons, badges, forms, modals and global surfaces.

### Visual preferences

- Dark, light or automatic mode.
- Optional custom accent color.
- Compact or comfortable density.
- Compact, standard or wide menu.
- Reduced-motion option.
- Instant visual preview without a full reload.

## Tests prioritaires / Priority testing

- Desktop avec plusieurs tailles de fenêtre / desktop at multiple window sizes.
- iPhone PWA portrait.
- iPad/tablette portrait et paysage / iPad/tablet portrait and landscape.
- Les six thèmes, notamment Light et High Contrast / all six themes, especially Light and High Contrast.
- Navigation entre les pages avec latence Proxmox volontairement élevée / page navigation with intentionally high Proxmox latency.
- Administration > Application pour vérifier les métriques de performance / Administration > Application performance metrics.
