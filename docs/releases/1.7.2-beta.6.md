# ProxPanel 1.7.2-beta.6 — PBS + Wazuh Security Essentials

## Français

Cette beta ajoute deux intégrations majeures sans remplacer les fonctions Proxmox/Docker existantes : **Proxmox Backup Server** et **Wazuh Security Essentials**.

### Proxmox Backup Server

- Connexion PBS par utilisateur/mot de passe ou token API.
- Diagnostic de connexion, version et état global.
- Datastores avec capacité totale, utilisée et libre.
- Restore points / snapshots et dernière sauvegarde connue par VM/LXC.
- Jobs Verify, Prune et Sync.
- Tâches PBS récentes et remontée des erreurs.
- Lancement manuel de Verify, Prune, Sync et Garbage Collection avec confirmation explicite et audit.
- Aucun restore automatique dans cette beta.

### Wazuh Security Essentials

- Connexions séparées au Wazuh Server API et au Wazuh Indexer.
- JWT Server API gardé uniquement en mémoire.
- Secrets Wazuh chiffrés localement et redacted dans les sorties.
- État Manager / Indexer, agents actifs, déconnectés et jamais connectés.
- Alertes importantes selon un niveau configurable, par défaut niveau 12 et supérieur.
- CVE Critical/High avec CVSS, machine, paquet/logiciel, version installée et version corrigée lorsqu’elle existe dans les données source.
- Priorité sécurité explicable par endpoint.
- FIM essentiel sur les modifications sensibles.
- Résumé brute-force, authentification, malware, élévation de privilèges et intégrité.
- Tendances Critical/High et nouvelles vulnérabilités.
- Corrélation Wazuh → VM/LXC → nœud Proxmox → environnement Docker/Portainer lorsqu’un mapping fiable existe.
- Aucun conteneur Docker précis n’est attribué sans donnée permettant de le confirmer.

### Notifications sécurité professionnelles

- Panel ProxPanel.
- E-mail HTML avec préfixe Wazuh, sévérité, endpoint, CVE/règle, CVSS, paquet, versions, MITRE, contexte Proxmox/Docker et action recommandée.
- Discord avec routage par salon et événements Wazuh dédiés.
- Événements : intégration indisponible/rétablie, agent déconnecté/reconnecté, CVE Critical/High, CVE résolue, hausse de critiques, alerte Wazuh importante et FIM sensible.
- Baseline silencieuse, déduplication et confirmation des déconnexions afin de limiter le bruit.

### Démo, PWA et sécurité

- Données fictives PBS/Wazuh dans le mode démo.
- Interfaces PBS et Wazuh responsive téléphone/tablette/PWA.
- Les pannes Wazuh partielles restent affichées comme **dégradées** et ne sont jamais transformées en faux état « 0 vulnérabilité ».
- Wazuh reste en lecture seule : aucune Active Response destructive.
- Images Docker officielles multi-architecture **linux/amd64** et **linux/arm64**.

## English

This beta introduces two major integrations without replacing existing Proxmox/Docker features: **Proxmox Backup Server** and **Wazuh Security Essentials**.

### Proxmox Backup Server

- PBS connection using username/password or API token.
- Connection diagnostics, version and health.
- Datastores with total, used and free capacity.
- Restore points / snapshots and latest known backup per VM/LXC.
- Verify, Prune and Sync jobs.
- Recent PBS tasks and errors.
- Manual Verify, Prune, Sync and Garbage Collection execution with explicit confirmation and audit.
- No automatic restore in this beta.

### Wazuh Security Essentials

- Separate Wazuh Server API and Wazuh Indexer connections.
- Server API JWT kept in memory only.
- Wazuh secrets encrypted locally and redacted from output.
- Manager / Indexer status and active, disconnected and never-connected agents.
- Important alerts based on a configurable rule level, defaulting to level 12 and above.
- Critical/High CVEs with CVSS, endpoint, package/software, installed version and fixed version when present in source data.
- Explainable endpoint security priority.
- Essential FIM for sensitive changes.
- Brute-force, authentication, malware, privilege escalation and integrity summaries.
- Critical/High trends and newly detected vulnerabilities.
- Wazuh → VM/LXC → Proxmox node → Docker/Portainer environment correlation when a reliable mapping exists.
- No specific Docker container is assigned without reliable evidence.

### Professional security notifications

- ProxPanel Panel notifications.
- HTML email with Wazuh prefix, severity, endpoint, CVE/rule, CVSS, package, versions, MITRE, Proxmox/Docker context and recommended action.
- Discord routing by channel with dedicated Wazuh event types.
- Events cover integration outage/recovery, agent disconnect/recovery, Critical/High CVEs, solved CVEs, critical spikes, important Wazuh alerts and sensitive FIM.
- Silent baseline, deduplication and confirmed disconnects reduce notification noise.

### Demo, PWA and security

- Deterministic PBS/Wazuh demo fixtures.
- Responsive PBS and Wazuh phone/tablet/PWA interfaces.
- Partial Wazuh failures stay **degraded** and are never converted into a false “0 vulnerabilities” state.
- Wazuh remains read-only: no destructive Active Response.
- Official Docker images remain multi-architecture for **linux/amd64** and **linux/arm64**.
