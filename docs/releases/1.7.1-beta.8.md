# ProxPanel 1.7.1-beta.8 — TV Mode & Administration Redesign

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version apporte une refonte complète du **Mode TV** et des pages Administration les plus visuellement datées.

### Mode TV

- Nouvelle vue **Synthèse** pensée pour un écran mural.
- Six KPI principaux : CPU, mémoire, stockage, réseau, température et santé.
- Nouveaux panneaux :
  - Alertes et problèmes
  - Nœuds
  - Sauvegardes
  - Mises à jour
  - Prévision de capacité
- Header entièrement repensé :
  - logo ProxPanel ;
  - état EN DIRECT ;
  - source/cluster ;
  - horloge ;
  - dernière actualisation ;
  - bascule Synthèse / Analytique / Studio.
- Hiérarchie visuelle renforcée pour une lecture à distance.
- Les vues Analytique et Studio reprennent la nouvelle identité visuelle.

### Responsive réel

Le Mode TV n'est plus un écran desktop simplement réduit.

- **Desktop / grand écran** : KPI sur une ligne et mur de supervision multi-colonnes.
- **Tablette** : recomposition en deux colonnes et commandes réparties sur deux lignes.
- **Mobile / PWA** : grille KPI compacte, panneaux empilés et contrôles horizontalement défilables.
- Mise en page dédiée aux écrans très étroits.

### Administration

#### Supervision

- Seuils présentés comme de vrais réglages.
- Libellé, description, valeur et unité clairement séparés.
- Mise en page compacte sans grands espaces inutiles.
- Meilleure lisibilité Light et Dark.

#### Avancé

- Suppression du champ d'ordre brut visible.
- Modules présentés dans une grille compacte.
- Contrôle du temps réel du dashboard séparé et mieux expliqué.
- Mise en page adaptative mobile.

#### Installation automatique OTA

- Refonte des fenêtres de maintenance.
- Numéro de créneau plus lisible.
- Jours présentés comme sélecteurs compacts.
- Début et fin regroupés en plage horaire.
- Les composants utilisent désormais les surfaces du thème au lieu de gros blocs noirs en Light.

## 🇬🇧 English

This release delivers a full **TV Mode** redesign and modernizes the most visually outdated Administration pages.

### TV Mode

- New **Summary** wallboard view.
- Six primary KPIs: CPU, memory, storage, network, temperature and health.
- New panels for alerts, nodes, backups, updates and capacity forecast.
- Fully redesigned header with ProxPanel branding, LIVE status, cluster/source, clock, refresh status and view switcher.
- Stronger visual hierarchy for distance readability.
- Analytics and Studio views inherit the new TV visual identity.

### True responsive layouts

TV Mode is no longer just a scaled-down desktop screen.

- **Desktop / wall display:** single-row KPIs and multi-column supervision grid.
- **Tablet:** two-column recomposition and wrapped controls.
- **Mobile / PWA:** compact KPI grid, stacked panels and horizontally scrollable controls.
- Dedicated very-narrow-screen layout.

### Administration

- Monitoring settings fully redesigned.
- Advanced page compacted and reorganized.
- OTA automatic-install maintenance windows redesigned.
- Reduced unused whitespace.
- Better Light/Dark theme consistency.
