# ProxPanel 1.7.1-beta.5 — Dashboard Loading Hotfix

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version corrige une erreur JavaScript critique visible après la mise à jour beta.3/beta.4 :

`notifyProblems is not defined`

Le dashboard récupérait bien les données Proxmox, puis échouait juste après lors de l'appel du gestionnaire de notifications manquant. ProxPanel affichait alors à tort **Données Proxmox indisponibles**.

### Correctifs

- Restauration de la fonction `notifyProblems()`.
- Le dashboard ne bascule plus en erreur après une récupération Proxmox réussie.
- Lecture plus robuste de l'historique local des notifications.
- Cache PWA renouvelé en beta.5.

## 🇬🇧 English

This release fixes a critical JavaScript error visible after beta.3/beta.4:

`notifyProblems is not defined`

The dashboard successfully fetched Proxmox data, then failed immediately afterwards because the notification handler was missing. ProxPanel therefore incorrectly displayed **Proxmox data unavailable**.

### Fixes

- Restores `notifyProblems()`.
- The dashboard no longer enters an error state after a successful Proxmox fetch.
- Hardens local notification-history parsing.
- Refreshes the PWA cache as beta.5.

## Tests prioritaires / Priority testing

- Mise à jour depuis beta.4.
- Dashboard serveur simple.
- Vue multi-nœuds.
- PWA iPhone après fermeture/réouverture.
- Notifications navigateur activées et désactivées.
