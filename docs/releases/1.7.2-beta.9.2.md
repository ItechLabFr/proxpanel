# ProxPanel 1.7.2-beta.9.2 — Console CSP hotfix

## FR

Cette version corrige une régression de la Content-Security-Policy introduite avec le durcissement sécurité de la série 1.7.2-beta.9.

- Réautorise explicitement `https://cdn.jsdelivr.net` pour les scripts frontend nécessaires à noVNC et xterm.js.
- Réautorise explicitement `https://cdn.jsdelivr.net` pour la feuille de style xterm.js.
- Rétablit l’ouverture du shell des nœuds Proxmox.
- Rétablit les terminaux LXC et les consoles série QEMU.
- Rétablit les consoles graphiques noVNC.
- Conserve la CSP, le RBAC fail-closed et les autres protections de la 1.7.2-beta.9.1.

### Symptôme corrigé

Proxmox pouvait journaliser :

```text
failed waiting for client: timed out
TASK ERROR: command '/usr/bin/termproxy ...' failed: exit code 1
```

Le proxy terminal était bien créé côté Proxmox, mais le navigateur ne pouvait pas charger xterm.js/noVNC ; le WebSocket console n'était donc jamais ouvert.

## EN

This version fixes a Content-Security-Policy regression introduced with the 1.7.2-beta.9 security hardening.

- Explicitly allows `https://cdn.jsdelivr.net` for the frontend scripts required by noVNC and xterm.js.
- Explicitly allows `https://cdn.jsdelivr.net` for the xterm.js stylesheet.
- Restores Proxmox node shells.
- Restores LXC terminals and QEMU serial consoles.
- Restores graphical noVNC consoles.
- Keeps the CSP, fail-closed RBAC and the other 1.7.2-beta.9.1 protections enabled.
