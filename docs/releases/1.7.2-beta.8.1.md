# ProxPanel 1.7.2-beta.8.1 — LXC OTA Hotfix

## Français

### Correction critique OTA LXC

- Corrige **« Impossible de lire release.json »** lors d’une mise à jour OTA depuis une installation LXC Debian 13.
- Le moteur de mise à jour n’impose plus `busybox unzip`.
- ProxPanel utilise désormais `unzip` natif lorsqu’il est disponible.
- BusyBox reste utilisé uniquement comme fallback compatible Docker/Alpine.
- La correction s’applique à :
  - lecture de `release.json` ;
  - extraction du package OTA ;
  - lecture du manifeste d’un package complet ;
  - extraction d’une mise à jour complète / réparation.
- Les messages d’erreur ZIP remontent maintenant la cause réelle.

### Installation LXC déjà en 1.7.2-beta.8

La Beta.8 contient encore l’ancien moteur. Pour permettre **une seule fois** la mise à jour OTA vers Beta.8.1 :

```bash
apt update && apt install -y busybox
```

Puis relancer la mise à jour depuis ProxPanel.

À partir de **1.7.2-beta.8.1**, BusyBox n’est plus requis dans le LXC pour les mises à jour ProxPanel.

## English

### Critical LXC OTA fix

- Fixes **“Unable to read release.json”** during OTA updates from native Debian 13 LXC installations.
- The updater no longer requires `busybox unzip`.
- Native `unzip` is now preferred when available.
- BusyBox is only used as a Docker/Alpine-compatible fallback.
- The fix covers OTA manifests, OTA extraction, full-package manifests and full update/repair extraction.
- ZIP errors now report the underlying extraction failure.
