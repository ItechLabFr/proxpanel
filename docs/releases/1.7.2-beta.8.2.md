# ProxPanel 1.7.2-beta.8.2 — CPU Model + Update UI Hotfix

## Français

### Processeur des nœuds

- Renforcement de la détection du modèle CPU.
- ProxPanel teste désormais plusieurs sources, dans cet ordre :
  1. informations déjà présentes dans les ressources cluster ;
  2. `/nodes/{node}/status` ;
  3. `/nodes/{node}/report` ;
  4. fallback SSH via `lscpu` / `/proc/cpuinfo`.
- Les sockets, cœurs et threads restent visibles même si le nom du processeur n’est pas encore accessible.
- La source utilisée est affichée dans l’interface.
- Les résultats négatifs sont mis en cache seulement quelques secondes afin de retenter rapidement.
- Si un token API ne permet pas de lire les informations matérielles du nœud et qu’aucun fallback SSH n’est disponible, le diagnostic l’indique clairement.

### Installation manuelle par ZIP

- Refonte complète des sélecteurs de fichier OTA et package complet.
- Le champ natif du navigateur n’est plus affiché directement.
- Nouveau bouton **Choisir un fichier** avec nom du ZIP sélectionné.
- Fin des débordements et superpositions dans les cartes.
- Responsive desktop, tablette et mobile.
- Les noms de fichiers longs sont tronqués proprement.

## English

### Node processor

- Hardened CPU model discovery.
- ProxPanel now tries cluster data, node status, node report, then SSH/lscpu.
- Core/thread data remains visible independently from the CPU model.
- The model source is displayed.
- Negative results use a short cache.
- Clearer diagnostics when API permissions or SSH availability prevent retrieval.

### Manual ZIP installation

- Completely redesigned OTA/full ZIP file pickers.
- Native browser file input no longer breaks the layout.
- Added a clean file selection control with selected filename.
- Fixed overflow and responsive behavior.
