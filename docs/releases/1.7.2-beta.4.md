# ProxPanel 1.7.2-beta.4 — Docker Dashboard & Proxmox Topology

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette beta ajoute un **Dashboard Docker complet** et la première topologie explicite entre Proxmox et les environnements Docker gérés via Portainer.

### Dashboard Docker

- Vue consolidée de tous les environnements Portainer.
- KPI : environnements, conteneurs running/stopped/unhealthy/restarting et stacks.
- Consommation CPU cumulée des conteneurs mesurables.
- Consommation RAM cumulée.
- Top conteneurs CPU.
- Top conteneurs RAM.
- Accès rapide vers l’environnement Docker concerné.
- Les métriques restent marquées indisponibles lorsqu’elles ne peuvent pas être récupérées : aucune valeur n’est inventée.

### Topologie Proxmox ↔ Docker

- Association explicite d’un environnement Portainer à une VM ou un LXC Proxmox.
- Suggestion assistée lorsque le hostname Docker correspond sans ambiguïté à une machine Proxmox.
- Une suggestion n’est **jamais appliquée automatiquement**.
- L’association peut être modifiée ou supprimée à tout moment.
- Vue du chemin VM/LXC → environnement Docker → stacks → conteneurs.
- Compatible avec plusieurs environnements Portainer et plusieurs machines Proxmox visibles dans ProxPanel.

### Démo publique

- Données Docker fictives maintenues pour le Dashboard.
- Deux hôtes Proxmox fictifs correspondent aux environnements Docker fictifs afin de montrer les suggestions de topologie.
- Aucune donnée réelle n’est exposée.

### Sécurité

- Docker reste accessible exclusivement via Portainer.
- Aucun montage de `/var/run/docker.sock`.
- Les modifications de topologie nécessitent les permissions opérateur/admin et sont auditées.
- Les API Key Portainer restent gérées comme dans les betas précédentes.

## 🇬🇧 English

This beta adds a complete **Docker Dashboard** and the first explicit topology between Proxmox and Docker environments managed through Portainer.

### Docker Dashboard

- Consolidated view of all Portainer environments.
- KPIs for environments, running/stopped/unhealthy/restarting containers and stacks.
- Aggregated measurable container CPU and memory.
- Top CPU and memory consuming containers.
- Quick navigation to the related Docker environment.
- Missing metrics remain unavailable; ProxPanel does not fabricate values.

### Proxmox ↔ Docker topology

- Explicit mapping from a Portainer environment to a Proxmox VM or LXC.
- Assisted suggestion when the Docker hostname matches exactly one Proxmox guest.
- Suggestions are **never applied automatically**.
- Mapping can be changed or removed at any time.
- VM/LXC → Docker environment → stacks → containers path.
- Works with multiple Portainer environments and multiple Proxmox guests visible in ProxPanel.

### Public demo

- Fake Docker data covers the new Dashboard.
- Two fake Proxmox hosts match the fake Docker environments to demonstrate topology suggestions.
- No real infrastructure data is exposed.
