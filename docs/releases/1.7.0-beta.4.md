**Type :** Historique documenté

## Températures et mode TV

Introduction de la télémétrie CPU via lm-sensors et du mode TV pour l’affichage permanent.

- Collecte des températures CPU des nœuds Proxmox via lm-sensors.
- Ajout du mode TV pour les écrans de supervision.
- Ajout dans l’image Docker des composants SSH nécessaires à la collecte distante.
