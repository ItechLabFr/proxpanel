# ProxPanel 1.7.0-beta.16 — Individual Node Temperature Fix

## 🇫🇷 Français

**Canal :** Beta  
**Thème :** Température des nœuds

### Correctif principal

Cette version corrige l'absence de température CPU dans les vues individuelles des nœuds Proxmox alors que la même information était déjà disponible dans les vues regroupées.

### Améliorations

- La collecte des températures des vues individuelles utilise maintenant le même enrichissement `lm-sensors` que les vues regroupées.
- La route live d'un serveur individuel renvoie désormais les températures des nœuds.
- La route dashboard d'un serveur individuel expose désormais les mêmes champs `temperatureC`, statut de collecte et diagnostics que la vue regroupée.

### Correctifs

- Corrige la température absente dans la vue individuelle d'un nœud.
- Corrige la disparition de la température lors du rafraîchissement live.
- Corrige l'incohérence des diagnostics de température entre vue regroupée et vue individuelle.

### Versioning

Cette release clôt exceptionnellement la série `1.7.0-beta.x`.

La prochaine série commencera en **`1.7.1-beta.1`**. À partir de `1.7.1`, une série ne pourra pas dépasser **10 betas** : `beta.1` à `beta.10`.

## 🇬🇧 English

**Channel:** Beta  
**Theme:** Node temperature

### Main fix

This release fixes missing CPU temperature values in individual Proxmox node views while the same information was already available in grouped views.

### Improvements

- Individual views now use the same `lm-sensors` temperature enrichment as grouped views.
- The individual server live route now returns node temperatures.
- The individual server dashboard route now exposes the same `temperatureC`, collection status and diagnostic fields as the grouped view.

### Fixes

- Fixes missing temperatures in individual node views.
- Fixes temperature values disappearing during live refresh.
- Fixes inconsistent temperature diagnostics between grouped and individual views.

### Versioning

This release exceptionally closes the `1.7.0-beta.x` series.

The next series will start at **`1.7.1-beta.1`**. Starting with `1.7.1`, each version series is limited to **10 beta releases**: `beta.1` through `beta.10`.
