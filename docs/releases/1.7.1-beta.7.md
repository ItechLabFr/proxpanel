# ProxPanel 1.7.1-beta.7 — Light Theme Completion & Admin Navigation

**Status:** GitHub prerelease  
**Channel:** Beta

## 🇫🇷 Français

Cette version finalise le thème clair et améliore fortement la navigation dans Administration.

### Thème Light

- Les notifications/toasts de succès, avertissement et erreur suivent désormais le thème clair.
- Correction des tuiles Maximum/Moyenne du widget Températures.
- Correction des blocs internes de Santé du cluster.
- Correction des métriques, informations, snapshots et en-têtes de la fenêtre détail VM/LXC.
- Correction de la barre de filtres du Monitoring.
- Correction des KPI Paquets/Critiques/Sécurité/Nœuds des mises à jour PVE.
- Correction de plusieurs zones OTA, SMTP, diagnostics, formulaires et modales encore sombres.

### Administration

- Nouveau menu secondaire permanent dans Administration.
- Rubriques disponibles :
  - Accueil
  - Général
  - Serveurs Proxmox
  - Interface & apparence
  - Supervision
  - Notifications
  - Utilisateurs & sécurité
  - Mises à jour
  - Application
  - Avancé
- Notifications et Utilisateurs ne sont plus séparés dans le menu principal.
- Le sous-menu reste visible pendant la navigation.
- Sur mobile, le sous-menu devient horizontal et défilable.
- Ajout d'un filtre rapide des rubriques Administration.

## 🇬🇧 English

This release completes the Light theme and significantly improves Administration navigation.

### Light theme

- Success, warning and error toasts now follow the Light theme.
- Fixes Maximum/Average Temperature widget tiles.
- Fixes internal Cluster Health blocks.
- Fixes VM/LXC detail metrics, information, snapshots and modal headers.
- Fixes the Monitoring filter toolbar.
- Fixes PVE Updates KPI cards for Packages/Critical/Security/Nodes.
- Fixes several OTA, SMTP, diagnostics, forms and modal surfaces that remained dark.

### Administration

- Adds persistent secondary navigation inside Administration.
- Available sections:
  - Home
  - General
  - Proxmox Servers
  - Interface & Appearance
  - Monitoring
  - Notifications
  - Users & Security
  - Updates
  - Application
  - Advanced
- Notifications and Users are no longer separate primary sidebar items.
- The secondary menu stays visible while navigating.
- On mobile, it becomes horizontally scrollable.
- Adds quick section filtering.

## Tests prioritaires / Priority testing

- Thème Light sur Vue d’ensemble, détail VM/LXC, Monitoring et Mises à jour PVE.
- Toasts succès / warning / erreur.
- Navigation Administration desktop.
- Navigation Administration sur iPhone/PWA.
- Notifications et Utilisateurs accessibles depuis Administration.
