# Archives de versions

Ce dossier contient les notes historiques de la branche 1.7 de ProxPanel.

- Les fiches **beta.1 à beta.13** sont des fiches historiques reconstruites à partir du suivi du projet. Elles ne prétendent pas être des snapshots Git du code de l'époque.
- À partir de **beta.14**, les versions peuvent être reliées à un commit, un tag et une GitHub Release reproductible.
- Si une archive officielle plus ancienne est retrouvée, sa fiche pourra être complétée avec SHA-256, ZIP complet, ZIP OTA et tag Git correspondant.

Voir aussi [l'historique global](../../HISTORY.md).
