# ProxPanel Roadmap

This roadmap is indicative and can change as the project evolves.

## Current priorities

- Continue improving FR/EN translation coverage and consistency.
- Improve dashboard and TV-mode customization.
- Improve VM console reliability and remote-session diagnostics.
- Improve temperature and hardware-monitoring diagnostics.
- Refine multi-node layouts and large-screen monitoring.
- Continue hardening OTA Stable/Beta update handling.
- Expand notification quality and alert testing.
- Improve accessibility, responsive behavior and PWA polish.

## Later

- Additional integrations where they provide clear operational value.
- More advanced capacity and historical analytics.
- More granular user permissions and audit workflows.

Feature requests are welcome through GitHub Issues.
